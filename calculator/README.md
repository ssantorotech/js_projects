# Calculator

A simple command-line calculator built with JavaScript.

## Description

This program allows users to perform basic mathematical operations by entering two numbers and choosing an operator.

Supported operations:

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)

The calculator also handles invalid inputs and division by zero.

## Technologies

- JavaScript
- Node.js
- prompt-sync

## Installation

1. Clone the repository.
2. Navigate to the project folder.
3. Install the dependencies:

```bash
npm install
```

## How to Run

```bash
node script.js
```
