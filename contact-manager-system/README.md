# Contact Management System

A simple command-line contact management system built with JavaScript.

## Description

This application allows users to manage a list of contacts through an interactive command-line menu.

Users can:

- Add new contacts with a name and email address.
- Delete contacts using their IDs.
- View all saved contacts.
- Search for contacts by name.
- Exit the application.

## Technologies

- JavaScript
- Node.js
- prompt-sync

## Installation

1. Clone the repository.
2. Navigate to the project folder.
3. Install the dependencies:

```bash
npm install
```

## How to Run

```bash
node script.js
```
