# Maze Adventure

A text-based adventure game built with JavaScript.

## Description

Explore a maze, make decisions, and try to find your way through the adventure using JavaScript.

## Technologies

- JavaScript
- Node.js

## How to Run

1. Clone the repository.
2. Navigate to the project folder.
3. Run the following command:

```bash
node script.js
```

## Concepts Practiced

- Variables and data types
- Conditional statements
- Loops
- Functions
- User input
- Basic game logic
