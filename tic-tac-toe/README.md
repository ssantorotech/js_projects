# Tic-Tac-Toe

A command-line Tic-Tac-Toe game built with JavaScript.

## Description

A two-player game where players take turns placing their symbols (X and O) on a 3x3 board.

The first player to align three symbols horizontally, vertically, or diagonally wins the game.

If all nine positions are filled without a winner, the game ends in a tie.

## Features

- Two-player gameplay
- Interactive command-line input
- 3x3 game board
- Input validation
- Win detection
- Tie detection

## Technologies

- JavaScript
- Node.js
- prompt-sync

## Installation

1. Clone the repository.
2. Navigate to the project folder.
3. Install the dependencies:

```bash
npm install
```

## How to Run

```bash
node script.js
```
